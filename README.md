# SYNAPSE: Distributed Collaboration Platform

## Overview
SYNAPSE is a Flask-based web application built to demonstrate advanced software engineering principles, including optimistic concurrency control, event-driven architecture, and background job processing.

## Features
- **JWT Authentication:** Secure login and role-based access control.
- **Document Versioning:** Historical tracking with optimistic locking to prevent silent overwrites.
- **Workflow Engine:** Strict state machine for document approvals (Draft -> Review -> Approved).
- **Event-Driven Architecture:** Transactional outbox pattern for reliable event processing.
- **Background Jobs:** Independent worker process for asynchronous tasks (e.g., exports).
- **Notifications & Audit Logs:** Automatically generated by the worker processing events.

## Tech Stack
- Python 3 / Flask / SQLAlchemy / SQLite
- HTML5 / CSS3 / JavaScript (Fetch API) / Chart.js
- Pytest for automated testing
